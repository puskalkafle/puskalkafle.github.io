About

(Kathmandu, NP)

I’m Puskal — a UX Engineer who lives in the overlap between design and code. I design interfaces, then build them: fast, accessible and pixel-faithful.

For the last several years I’ve specialized in designing and optimizing user interfaces for web applications — enhancing frontend performance, improving accessibility, and translating design concepts into functional, user-friendly products. The same instinct led me to ship my own: an AI image-upscaling platform with apps on Shopify and WordPress, and a set of production-grade components on the Framer Marketplace.
